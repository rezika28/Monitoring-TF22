☁️ Sambungkan Database Firebase

Isi konfigurasi dari Firebase Console satu kali pada perangkat admin. Untuk online bersama, semua pengguna harus membuka aplikasi yang sama dengan konfigurasi Firebase yang sama.

Mode lokal: data hanya ada di browser ini sampai Firebase disambungkan.

Jangan gunakan aturan database publik. Aktifkan Authentication → Anonymous dan gunakan aturan yang mensyaratkan auth != null. Konfigurasi Web Firebase bukan kata sandi, tetapi jangan pernah membagikan service-account key atau kredensial admin.
